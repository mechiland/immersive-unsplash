# Immersive Unsplash privacy policy

Immersive Unsplash changes the layout of supported Unsplash pages in your browser. To do this, it reads and modifies website content and navigation elements on unsplash.com. When an account menu is present, it reads the displayed account name and username to arrange that menu. It also checks the current page URL and scroll position to apply the layout. All of this processing happens locally and only supports the extension's layout features.

The extension does not persist or transmit this information, send it to the developer or any third party, sell or share it, or use it for analytics or tracking. Its use of information adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

The extension does not make its own network requests or execute remotely hosted code. Unsplash continues to receive information and operate according to its own privacy policy when you use its website; this extension does not control Unsplash's data practices.

For questions, use the developer contact information on the extension's Chrome Web Store listing.
