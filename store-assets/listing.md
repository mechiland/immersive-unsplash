# Chrome Web Store listing

## Detailed description

Browse Unsplash with a streamlined desktop layout. Immersive Unsplash moves browsing navigation into a compact top bar, giving the photo and illustration feed more room while keeping Unsplash's original content and controls.

- Browse photos, illustrations, topics, and search results in a wider layout.
- Continue using Unsplash's original search, account menu, photo actions, and other site features.
- Return automatically to Unsplash's standard layout when the browser window is narrower than 1024 CSS pixels or a page is not supported.

Designed for the English desktop version of Unsplash. Changes to Unsplash's website may affect compatibility. This independent extension is not affiliated with or endorsed by Unsplash.

## Single purpose

Rearrange the navigation and browsing layout on Unsplash desktop pages.

## Site access justification

Access to https://unsplash.com/ is needed to detect supported pages and adjust their navigation and layout locally in the browser.

## Remote code

The extension does not load or execute remotely hosted code.
